# Enterprise AI Incident Intelligence & Risk Analytics Platform

## 📌 Project Overview
This project is an enterprise-level incident analytics and machine learning platform developed using MySQL, Python, Machine Learning, and Power BI.

The system analyzes operational incidents, calculates risk scores, identifies critical incidents, and provides business insights through interactive dashboards.

---

## 🚀 Technologies Used

- MySQL
- Python
- Pandas
- Scikit-learn
- Power BI

---

## 📊 Features

- Incident Risk Scoring
- ML-Based High Risk Prediction
- Operational Analytics
- Executive KPI Dashboard
- System-Wise Risk Analysis
- Critical Incident Monitoring

---

## 🧠 Machine Learning

Implemented Logistic Regression model to identify high-risk operational incidents based on:
- Severity
- Priority
- Resolution Days

---

## 📈 Power BI Dashboard

### Page 1 — Executive KPI Dashboard
- Total Incidents
- Average Risk Score
- Predicted Critical Incidents

### Page 2 — Operational Risk Analytics
- Severity Distribution
- Priority Distribution
- System-Wise Risk Analysis
- Critical Incident Monitoring
